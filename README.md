# Scroll Title Progress Bar

**Scroll Title Progress Bar** is a modern WordPress plugin that adds an interactive reading progress indicator at the bottom of the screen. It not only shows how much content is left to read but also displays the current section's heading.

## Key Features

- 🚀 **Dynamic Headings:** The indicator automatically detects the current heading (H2, H3, etc.) as you scroll and displays its title.
- 📊 **Progress Indicator:** A smooth progress bar visualizing the page scroll depth.
- 🛠 **Full Customization:** Control colors, height, opacity, and font size directly from the admin panel.
- 📱 **Responsive Design:** Works perfectly on both mobile devices and desktops.
- 🎯 **Flexible Display:** Choose where to show the plugin (posts or pages) and exclude specific pages by their ID.
- 🖱 **Fast Navigation:** Clicking on the heading in the bar triggers a smooth scroll to the first heading on the page.

## Installation

1. Download the plugin archive.
2. Go to **Plugins > Add New** in your WordPress dashboard.
3. Click **Upload Plugin** and select the downloaded file.
4. Activate the plugin after installation.

## Configuration

After activating the plugin, a new menu item — **Scroll Progress Bar** — will appear in your WordPress sidebar.

In the settings, you can:
- Select content types for display (Posts/Pages).
- Specify heading tags to track (separated by commas, e.g., `h2,h3,h4`).
- Exclude specific pages by their IDs.
- Customize appearance: bar color, block height, background opacity, and heading text size.
